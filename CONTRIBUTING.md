# Contribuire

VoidOS è un OS x86-64 personale in sviluppo (C, Rust, Assembly).

- Per modifiche grandi apri prima una issue per allinearsi.
- Compila e testa secondo le istruzioni nel [README](README.md).
- Prima di aprire una PR:
  - assicurati che build, test host e boot QEMU (`ordinary`) passino;
  - tieni il diff pulito (4 spazi, niente file di `build/` o temporanei);
  - scrivi brevemente cosa cambia e cosa hai provato davvero.

Il codice segue la licenza [GPL-3.0-only](LICENSE).
