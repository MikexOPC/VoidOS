# Sicurezza

VoidOS è un sistema operativo sperimentale in sviluppo sul branch `main`.

Se trovi una vulnerabilità (corruzione memoria, bypass privilegi, bug nel loader o nei driver):
- usa **Report a vulnerability** nella sezione [Security Advisories](https://github.com/MikexOPC/VoidOS/security/advisories) del repo;
- in alternativa apri una issue chiedendo un contatto privato a [MikexOPC](https://github.com/MikexOPC), senza pubblicare subito exploit o dettagli sensibili.

Indica commit, passi per riprodurre e log utili.
